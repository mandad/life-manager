# Daily data records

One file per /daily run, foldered by month: `YYYY-MM/YYYY-MM-DD.md` — **filename = the date the file describes** (yesterday, for a morning run). Each captures that day's data-source pulls + single-day observations; multi-day patterns go to memory instead.

Also lives here: per-source state files (sync watermarks, the {{FLOURISH_SLUG}} registry if the daily-flourish module is active) and `../_weekly-data/` as the parallel weekly record.
